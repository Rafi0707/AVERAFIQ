# Contributing to AVERAFIQ

Thanks for your interest! The project is at a very early stage, so the most useful help right now is:

- Feedback on the plan in the README and docs/ROADMAP.md
- Bangla and English wording and translations
- UI and accessibility ideas, especially for elderly users
- Bug reports and code once the first version is published

## How to help
1. Open an issue to discuss your idea first, especially for larger changes.
2. Fork the repository, make a focused change, and open a pull request.
3. Keep pull requests small and explain what and why.

## Ground rules
- Be kind and respectful.
- Never commit API keys, signing keys or personal data.
- By contributing, you agree your work is licensed under Apache-2.0.
