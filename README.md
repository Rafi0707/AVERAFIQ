# AVERAFIQ

**Your private AI. Your everyday companion.**

AVERAFIQ is an Android-first, open-source personal assistant for students, elderly users and people who live alone. It keeps notes, tasks and reminders on your phone and adds an optional AI chat that you power with your own API key.

> **Status: planning / pre-alpha.** No app has been released yet. This repository currently holds the product plan. The first code (v0.1) is being started now.

## Why

- Many everyday productivity apps need an account, a subscription or a cloud service.
- Bangla support is often missing or poor.
- Quiet, independent users (students, older people, people living alone) deserve simple tools that respect their privacy.

## Principles

1. **Local-first:** notes, tasks and memories stay on your phone.
2. **Works without AI:** notes, tasks and reminders work with no account and no API key.
3. **Bring your own key:** AI chat is optional; you choose the provider and see what is sent.
4. **You control your data:** view, edit, export and delete everything.
5. **Bangla and English** from the start.
6. **No hidden tracking.**

## Planned scope

| Version | Goal |
|---|---|
| v0.1 | Notes, tasks, reminders, AI chat (bring-your-own-key) |
| v0.2 | Local memory you can edit, simple search, basic voice input |
| v0.3+ | Study helper, expense tracker, scheduled automations, elderly-friendly mode |

Details are in [docs/ROADMAP.md](docs/ROADMAP.md). Scope can change.

## Not planned

Automatic SMS or payments, unrestricted control of other apps, mandatory accounts, or secret data collection.
