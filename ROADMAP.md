# Roadmap

Plans can change. Nothing below is released yet.

## v0.1: Foundation
- Android app (Kotlin, Jetpack Compose), local database
- Notes: create, edit, pin, search
- Tasks: create, complete, organize
- Reminders: local notifications
- AI chat with a configurable provider and your own API key
- Bangla and English interface
- Everything except AI chat works offline, with no account

## v0.2: Memory
- Memories you save, edit and delete yourself
- Simple search across notes, tasks and memories
- Basic voice input

## v0.3 and later (ideas)
- Study planner and flashcards
- Expense tracker and shopping list
- Scheduled reminders and simple automations
- Elderly-friendly mode (large text, simple navigation)
- Optional local AI models

## Principles for every release
- Ask before any sensitive action; show what is sent to an AI provider.
- Keys and personal data never go into the repository.
